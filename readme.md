# Instagram Downloader

## ⚠️ 【重要】注意事項
- **アカウントのリスクについて**: 短時間に連続して大量のダウンロードを行うと、Instagramからスパム行為と見なされ、一時的なアクセス制限やアカウント停止措置を受ける恐れがあります。
- **使用間隔**: 連続使用は避け、1件ごとに十分な間隔を空けてください（スクリプト内でもランダムな待機時間を設けていますが、過度な利用は控えてください）。
- **ログインの推奨**: API制限の回避や高画質メタデータの取得、安定した動作のために、ご自身のアカウントでのログインを強く推奨します。
- **公開設定**: 基本的に公開アカウントの投稿のみを対象としています。
- **免責事項**: 本ツールの利用により生じたトラブル、損害、アカウントの制限等について、開発者は一切の責任を負いません。自己責任でご利用ください。

## 概要
Instagramの投稿（画像・動画）のURLを入力するだけで、簡単にローカル環境へ保存できるGUIアプリケーションです。`instaloader`ライブラリを使用し、ログインセッションの保持機能も備えています。

## 動作要件
- Python 3.x
- `instaloader` ライブラリ

### ライブラリインストール方法
```bash
pip install instaloader
```

## 使い方
1. `insta_app.py` を実行します。
2. **ログイン設定**:
   - ユーザー名とパスワードを入力して「ログイン」ボタンをクリックします。
   - 成功するとセッションが保存され、次回以降は保存されたセッションが優先的に読み込まれます。
3. **ダウンロード**:
   - Instagram投稿のURL（`https://www.instagram.com/p/...` など）を貼り付けます。
   - 「ダウンロード開始」をクリックします。
4. **完了後**:
   - ダウンロードが完了すると、保存先のフォルダが自動的にエクスプローラー（またはFinder等）で開きます。

## 保存先について

### 1. ダウンロードされたファイル
OSの標準的な「ダウンロード」フォルダの中に作成される専用ディレクトリに保存されます。投稿者（ユーザー名）ごとにフォルダが自動生成されます。
- **パス**: `~/Downloads/Instagram_Downloads/{ユーザー名}/`

### 2. セッションファイル
再ログインの手間を省くためのセッション情報は、`instaloader`の標準仕様に従い、以下の場所に保存されます。
- **Windows**: `%APPDATA%\Instaloader`
- **macOS/Linux**: `~/.config/instaloader`

## 主な機能
- **自動ログイン**: 保存されたセッションがある場合、自動的に再利用します。
- **マルチスレッド**: ダウンロード中にアプリの画面がフリーズしません。
- **エラーハンドリング**: 403制限や非公開アカウント、URLの間違いなどを通知します。
- **検知回避**: リクエスト間に1〜3秒のランダムな待機時間を挿入します。

## 開発者向け
- `insta_downloader.py`: ダウンロードロジック（`instaloader`のラッパー）
- `insta_app.py`: `tkinter`を用いたUIの実装(起動ファイル)
